# Colors & themes

## Options

Every color is a role, and each theme gives every role its value: light, dark, and both at high contrast. People choose one, or the application follows their system.

## Rules

Choose the role for what an element is, never the color it should have. A tone always comes with words or an icon, so nobody has to tell colors apart.

## Compose

### Usage

Put the interface inside `Theme`; a nested `Theme` gives one region another theme or contrast. `useTheme()` returns the nearest one's settings, and `useThemePreference()` the theme preference with `setPreference` and `toggleTheme`. Tokens are named `--env-color-{bg|fg|border}-{role}[-{emphasis}][-{state}]`, and a `fg-on-X` goes on its `bg-X`.

```tsx
import { Theme, Text, useTheme } from '@envsemble/envui';

function ThemeLabel() {
  const { theme, contrast } = useTheme();
  return (
    <Text>
      Current theme: {theme}, {contrast} contrast
    </Text>
  );
}

<Theme theme="dark" contrast="high">
  <ThemeLabel />
</Theme>;
```
