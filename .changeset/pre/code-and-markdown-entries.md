The `@envsemble/envui/content` entry is two, named after what they hold: import Code and CodeBlock from `@envsemble/envui/code`, and Markdown, MarkdownEditor and their types from `@envsemble/envui/markdown`; an application that shows only code no longer installs react-markdown and remark-gfm ([setup](https://github.com/envsemble/envUI/blob/main/docs/setup.md)).
