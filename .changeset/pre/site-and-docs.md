envUI's documentation is hosted in two parts. The Site, at the root, introduces envUI: its components, patterns and foundations, with a Benchmark and a Changelog of short release notes. The Docs, under `/docs`, are the developer reference: setup, migration, the codemods, agent tooling, dev mode, the foundations' guides, the design tokens and each component's props, part names and changelog. The top bar links one to the other, and search finds the pages of both. The offline catalogue, `envUI.html`, and the archived versions built from it are gone, so a release no longer attaches it; a hash address of an earlier release opens its page at the plain path.
