A Calendar, on its own or in a DatePicker's popup, names the weekdays one way at every width and scale: by their first two letters, Mo Tu We in English, where those tell the seven apart, else by the locale's narrow names where those do, so the names never run into each other in the narrowest days. Each column's header still carries the full name for assistive technology.
