`windowClassOf(inlineSize)` gives the window class of a width in CSS pixels, such as `useContainerSize`'s `inlineSize`, at the root font size, so code that renders by the window class needn't convert the rem of `windowClasses` itself. See [Adapting to width](https://github.com/envsemble/envUI/blob/main/docs/foundations/responsive.md).
