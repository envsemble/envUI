The contract data is importable: `@envsemble/envui/parts.json` (part classes, state attributes and custom properties), `@envsemble/envui/props.json` (every export's props) and `@envsemble/envui/tokens.json` (the token list, which the package now ships). Dev mode takes `import parts from '@envsemble/envui/parts.json'` where it can't fetch its own copy.
