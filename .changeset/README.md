# Changesets

Each other Markdown file here is a pending changelog entry for `@envsemble/envui`, written with `npm run changeset`. `npm run changeset:version` turns them into the next version and its section of `packages/ui/CHANGELOG.md`. `pre.json` keeps versions on the `next` prerelease line until `npx changeset pre exit`.

See "Record the change" in `docs/library-development.md` and "Releases" in the README.
