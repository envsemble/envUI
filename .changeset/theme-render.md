Theme takes `render`, like Box and Text: its boundary can be the element a region needs, such as `render={<section />}` for a landmark or `render={<tbody />}` inside a table, with the boundary's class and attributes merged into it, instead of an extra div. See [Setup](https://github.com/envsemble/envUI/blob/main/docs/setup.md#theme).
