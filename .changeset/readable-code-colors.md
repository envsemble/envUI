Highlighted code is readable in both app themes. Code blocks and code diffs keep the Pierre code themes, but each token color below 4.5:1 on code's background takes the closest color of the same hue and chroma that reaches it: in the light theme the oranges, yellows, greens and cyans are darker, and in the dark theme the grey of comments and JSX text is lighter. Code diffs also keep their tokens readable on the lines they tint for additions and deletions, and their change counts on code's background.
