The codemods cover what a run over real applications left to hand work:

- `v1-props` maps each literal of a conditional value, also in nested ternaries and beside `&&`, `||` and `??`: `tone={failed ? 'error' : 'info'}` becomes `tone={failed ? 'danger' : 'info'}`, and a value 1.0 drops as the default becomes `undefined`. It deletes Code's `appearance`, Markdown's `inlineCode` and CodeBlock's `theme`, which 0.7 removed, and reports one that is an expression.
- `v1-render` turns a ternary of element names into a ternary of elements: `as={section ? 'h2' : 'h1'}` becomes `render={section ? <h2 /> : <h1 />}`.
- `v1-classes` rewrites the uses of a removed custom property that one token replaces as it is, rather than reporting them: `var(--control-height-small)` and `var(--icon-button-size)` become `var(--env-control-height)`, `--control-height-compact` `--env-control-height-sm`, and `--color-surface-base` and the other unused 0.7 colors their roles. A declaration is rewritten only where the old name is the one that becomes the token, the only one or the token's own name: where 1.0 merges several names into one token, as `--control-height`, `--control-height-small` and `--icon-button-size`, or a 0.7 alias and its role, a declaration of any other of them stays and is reported, since rewriting it would set the token for every component that reads it, and no block gets two declarations of one property. It renames classes and tokens in CSS-in-JS templates tagged `css`, `keyframes`, `createGlobalStyle`, `injectGlobal` or `styled`, in test locators (`locator()`, `waitForSelector()`, `$()`), `toHaveClass()` and `expect(el.classList)` assertions, and, in test files, a string that is exactly one 0.x class passed to a call that names classes, such as `findByClass()`, or one class selector passed to any call. Another exact class string there, such as a `data-testid`, an id or an object key, is reported, as are a 0.x class in a regular expression or a longer string, a token's name in a regular expression, and a style for `env-code-subtle`. A test file is told by its path below the folder the run scans, so a project kept in a `tests` folder is not all test files.
- `v1-props` leaves a removed prop whose value mixes literals and an expression, such as `appearance={dark ? 'dark' : level}`, whole, and reports it.
- `v1-app-shell` puts NavList items behind a condition, in a fragment or from a `map` into the `NavList.Root`, and reports a navigation whose items sit beside other content or that it can't see into.
- `v1-names` reports ActionGroup, ActionCard, FeatureCard and AppShellSkeleton only where they are used other than as elements, which `v1-structure` and `v1-app-shell` rewrite.
- Declaration files (`.d.ts`, `.d.mts`, `.d.cts`) parse as declarations, so a run no longer fails on them.
