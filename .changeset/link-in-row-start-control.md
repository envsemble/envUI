`no-link-in-clickable-row` passes a link in a clickable `List.Item`'s `start` or `control`, as it did in `end`: those slots sit above the row's target, so an Avatar in `start` that links to the person's profile works beside a row that opens the item. See [no-link-in-clickable-row](https://github.com/envsemble/envUI/tree/main/packages/eslint-plugin#no-link-in-clickable-row).
