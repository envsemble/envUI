The code theme changed: inline code, code blocks, code diffs and the code in Markdown use Shiki's `github-light-default` theme in the light theme and `github-dark-dimmed`, a grey dark theme, in the dark one, instead of the Pierre themes. Under high contrast (a Theme's `contrast="high"`, or `system` while `prefers-contrast: more`) they take `github-light-high-contrast` and `github-dark-high-contrast` rather than the standard themes with darker or lighter tokens, and load them only once code shows at high contrast. Inline code and code blocks sit on translucent layers of the text color, inline code on the neutral muted fill (`--env-color-bg-neutral-muted`) and blocks on a layer of their own, so they stand a step apart from the page, panes, cards, muted fills and list items, and popups alike, darker in the light theme and lighter in the dark one; diffs sit on an opaque muted grey, light in the light theme and blue-grey in the dark one; code in the dark theme is no longer near black. Diffs color added and removed lines with the themes' greens and reds. Every token still reaches 4.5:1, and 7:1 under high contrast, on the backgrounds it sits on, over each of those surfaces; a few token colors are a little darker in the light theme and lighter in the dark one for it. The themes come with Shiki, so the content and diff entries no longer need the optional peer `@pierre/theme`: remove it unless the application uses it itself. Corners, padding and the copy button are unchanged.
