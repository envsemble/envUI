The code theme changed: inline code, code blocks, code diffs and the code in Markdown use Shiki's `github-light-default` theme in the light theme and `github-dark-dimmed`, a grey dark theme, in the dark one, instead of the Pierre themes. Under high contrast (a Theme's `contrast="high"`, or `system` while `prefers-contrast: more`) they take `github-light-high-contrast` and `github-dark-high-contrast` rather than the standard themes with darker or lighter tokens, and load them only once code shows at high contrast. Inline code sits on the theme's own color for code in text, and code blocks and diffs on a muted grey a step from the page, light in the light theme and blue-grey in the dark one; code in the dark theme is no longer near black. Diffs color added and removed lines with the themes' greens and reds. Every token still reaches 4.5:1, and 7:1 under high contrast, on the backgrounds it sits on. The themes come with Shiki, so the content and diff entries no longer need the optional peer `@pierre/theme`: remove it unless the application uses it itself. Corners, padding and the copy button are unchanged.
