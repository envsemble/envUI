CodeBlock and HighlightedCodeBlock: `label` takes any content, such as a file-type icon with a path link, with `textValue` naming the code for assistive technology where the label isn't a string. `actions` places content in the heading before the copy button, such as Open in editor, Run, or a switch between npm, pnpm and yarn. See [Code](https://github.com/envsemble/envUI/blob/main/docs/components/code.md).
