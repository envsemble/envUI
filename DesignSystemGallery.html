Grouped rows

Related rows form one rounded group. The exposed outer corners are soft; the corners between rows are tight. The rounding follows each row’s position in the group.

Two colors define the pattern: page background and row fill. Place rows directly on the page background. Keep the same row fill across single rows, grouped lists, settings, and member rows. The number of rows changes the corners, not the color. Additional card backgrounds and alternating row colors are not part of this pattern.

Workspace settings

    Change the count to see the corners adapt. Use this pattern for settings, member lists, product seats, and billing groups. Treat each separate group independently.
