Toggle

Size & behavior

Track: 2.5 × 1.5 rem. Thumb: 1 rem; inset: 0.25 rem. Off: row fill. On: control blue, identical in both themes. Both states use the shared lightness rule. Space toggles; apply the change immediately.

    Usage & spacing

    Neutral: general feedback. Success: completed. Info: update. Error: failed.

    Toast exception: 0.5 rem corners. 0.5 rem vertical / 0.75 rem horizontal padding, 0.5 rem gap. Muted fills and white text stay the same in both themes. Error uses the delete button color.

    Fit content · 3 rem minimum height. Material Symbols Rounded · 400 weight · grade 0 · optical size 24 · 1.125 rem display size. Optional action uses primary button sizing and the shared lightness rule. Its default fill keeps the toast hue and saturation, with lightness × 0.78. Labels and icons stay white. The × control is optional. Keep messages short and on one line. Without ×: brief feedback may clear automatically. Errors stay visible until dismissed.

    Viewport inset: 1 rem. Stack gap: 0.5 rem. Keep icons, message, action, and dismiss control in one row. Truncate the message only when space is limited; never add a scrollbar. Use status for routine feedback and alert for errors.

    Layout & behavior

    Pane fill; 1.75 rem corners; 1.5 rem padding and content gaps. Actions: 1 rem gap, aligned to the end; wrap when needed. Width: up to 28 rem, leaving 1 rem around the viewport. Scroll the dialog when content exceeds the available height.

    Overlay: dark canvas at opacity in both themes. Focus starts on Cancel for destructive confirmation, or the first field for a form. Tab stays inside; Escape or Cancel closes; focus returns to the opener. Outside click closes confirmation; form dialogs keep edits until Save or Cancel.
