Button layout rules

Content & alignment
0.875 rem label · 1.4 line height · 0.4375 rem icon gap. Center content on both axes.
Padding
Vertical: 0.25 rem. Horizontal: 0.75 rem.
Border & focus
Secondary/outlined border: 0.0625 rem. Other buttons: none. Focus outline: 0.125 rem. Use border-box sizing.
Size & corners
Minimum height: 2 rem. Width fits content. Wrap long labels. Pill corners; purple emphasis: 0.5 rem.
Outer spacing
No button margin. Parent gap: 1 rem horizontally, 0.5 rem stacked.
Icon-only buttons
2 rem square · centered 1 rem icon · no horizontal padding · accessible name required.
Navigation controls
Minimum height: 2.5 rem. Text: 0.9375 rem / 1.4. Padding: 0.25 rem × 0.75 rem. Icon gap: 0.5 rem. Content-fit width.
