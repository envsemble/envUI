# Changelog

## 1.0.1 — 2026-11-13

A fix for phones: a tapped control no longer shows the browser's square tap highlight.

### Patch Changes

- A tapped control on a phone no longer shows the browser's rectangular tap highlight over it; the control's own press feedback shows instead.

## 1.0.0 — 2026-11-12

The first stable release of envUI: a React design system of components, patterns and foundations for B2B SaaS products and AI developer tools, with its documentation in the package for people and coding agents. It is free and open source under the MIT license. From here, a breaking change waits for a major version. To start, read [Install and set up](https://envui.envsemble.com/docs/setup).
